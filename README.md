# Mahammad Sayyad Asraruddeen — Digital Marketing Portfolio

A focused personal portfolio presenting Mahammad's digital marketing, web, SEO, paid media, analytics, creative, and leadership experience. The single-page experience is designed for recruiters and hiring managers, with selected project stories, an experience timeline, direct contact links, and a downloadable CV.

## Technology

- TanStack Start and React 19
- TypeScript and Vite
- Tailwind CSS 4 with a custom responsive design system
- Lucide icons
- Netlify Image CDN for optimized portrait delivery
- Netlify deployment adapter

## Run locally

Install dependencies and start the development server:

```bash
pnpm install
pnpm dev
```

The production build is created with `pnpm build`.

## Key files

- `src/routes/index.tsx` contains the portfolio content and page structure.
- `src/styles.css` contains the visual system, responsive layouts, and motion.
- `src/routes/__root.tsx` defines site metadata.
- `public/assets/` contains the optimized-source portrait and downloadable CV.
